# Fictional Newleaf export samples

Generated by the app exporters during the recorded ReleaseSamplesTest. These are acceptance fixtures with invented nutrition and a one-pixel PNG, not the owner’s diary, measured food facts or recommendations. Opening the app never imports them automatically.

| File | Purpose |
| --- | --- |
| example-journal.json | Canonical schema1.0 records and structured views |
| example-report.md | Readable daily report |
| example-spreadsheets.zip | 18 CSV views plus canonical journal.json, dictionary/report and integrity metadata |
| example-backup.zip | Full fixture backup with original placeholder attachment bytes |

Use JSON/ZIP with Restore to test a disposable journal; CSV files alone are not a restore source. Keep a full backup of personal data before replace restore. [Export/restore contract](../../docs/DATA_AND_EXPORTS.md) explains nulls, context, coverage, source notices and the legacy app-version manifest label. Checksums are in releases/CHECKSUMS.txt.
